What's new in 1.3.6

  • Random start, fixed duration — new schedule mode: exact daily total (e.g. 8 h 23 min), break ± variation, start window; fresh random times on every fill.
  • Conflict handling — choose what happens when a day already has time entries: Skip (default) or Replace (delete that day's entries and book your blocks). Handy for cleaning up duplicates.
  • Update notice — a banner and notification tell you when a newer version is available (opt-out in Options → Updates).
  • Reliable duplicate check — it now inspects your actual time entries for the day and never books when the check fails.
  • Security & privacy section (below) and a published privacy policy.
  • Fixes: legacy hours migration, DST-safe daily alarm, transactional multi-block booking, timezone edge cases.
  • From 1.1.0: flexible working blocks with day timeline, your own timezone, auto-fill catch-up, customer & service picker, redesigned UI, this guide.

1Install the extension

  1. Unzip the download (or clone the repo) to a folder you will keep.
  2. Open chrome://extensions.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and pick the folder.
  5. Pin the icon from the puzzle-piece menu.
Don't delete or move the folder afterwards — Chrome loads the extension from there.
Developer mode on → Load unpacked → pick the folder

2Get your personal API key

  1. Sign in to Clockodo and open My area → Edit self.
  2. Find the API key section.
  3. Copy the key (generate one if the field is empty).
This is not your password. The key stays in your browser's local storage and is sent only to my.clockodo.com. Every colleague uses their own key — nothing is shared.
My area → Edit self → API key → Copy

3Connect the extension

  1. Click the extension icon → Options.
  2. Enter your Clockodo login email and paste the API key.
  3. Click Test connection — you should see your name with a green check.
  4. Press Save in the top bar.
Green check = the key works

4Choose customer & service

Clockodo books your attendance as time entries, so each entry needs a customer and a service (e.g. your internal company customer and a generic "Work" service).

  1. In What to book, keep mode = Time entries.
  2. Click Load customers & services.
  3. Pick the customer and service your team uses for regular work.
  4. Leave "billable" off unless told otherwise. Save.
Not sure which to pick? Open any existing entry in Clockodo and use the same customer/service shown there.
Load once, then pick from the dropdowns

5Set your working hours

Fixed blocks: start with one block (default 09:00–17:00). Click + Add block to split the day — the gap between blocks is your break, e.g. 08:30–13:00 and 14:00–17:30.

Random start, fixed duration: set the exact daily total (e.g. 8 h 23 min), a break with an optional ± variation, and a start window (e.g. 07:30–09:30). Every fill draws fresh values — start, break length and the morning/afternoon split — while the total stays exact. Running Replace again re-rolls the day. Preview next days shows sample results.

  • Pick your Timezone below. All times are wall-clock in that zone and DST-aware.
  • Keep Skip weekends on unless you actually work weekends.
Two blocks, one break

6Turn on automatic daily fill

  1. In Schedule, set the time (default 09:15) and switch on Auto-fill every workday. Save.
  2. Or toggle Auto-fill daily right from the popup.

How it behaves:

  • At the set time, while Chrome is running, it fills today — unless it's a weekend, an opted-out day, or already filled.
  • If Chrome was closed at that time, it catches up the next time Chrome starts (once per day).
  • You get a notification only when something was created or failed. Silence = nothing to do.
The popup shows Next run and the result of the last automatic run.
Checks first, books only when needed

7Day-to-day use

  • Fill today — one click. Shows created, already filled, or skipped.
  • Fill range — pick From/To (or tap This week / Last week / This month), fills every workday in between. The status line tells you the exact range it is booking.
  • If a day already has any time entry — Skip that day (default, never touches existing bookings) or Replace (deletes all entries on those days and books your blocks — asks for confirmation; use it to clean up duplicates).
  • Skip today — mark today as a day that must not be filled (sick day, holiday). Manage the full list in Options.
  • The dot next to your name is green when the API key works.
  • The footer shows your installed version and whether a newer one exists, plus the last automatic run.
Everything you need is in the popup

Security & privacy — in plain words

  • Official API only. The extension talks to Clockodo exclusively through its documented public REST API (https://my.clockodo.com/api), the same one Clockodo's own integrations use. No scraping, no automation of the website, no hidden endpoints.
  • Your data stays on your computer. Your email, API key and settings are stored in the extension's local storage inside your Chrome profile. They are never synced, uploaded, or shared. There is no server behind this extension, no account, no analytics and no crash reporting.
  • Only one destination for your data. Every request carrying your credentials goes to my.clockodo.com, and only when you click Fill / Test / Load or the scheduled fill runs. The extension has no permission for any other website.
  • Optional update check. Once a day it downloads one public file (the project's manifest.json on GitHub) to see if a newer version exists. That request contains no personal data at all. Turn it off in Options → Updates if you prefer.
  • API key, not password. You never enter your Clockodo password. The personal API key can be regenerated in Clockodo at any time, which instantly invalidates the old one.
  • Nothing runs without Chrome. There is no background service or cron job on your machine. The daily auto-fill is a Chrome alarm: it fires only while Chrome is running, and catches up on the next launch if it was missed.
  • Everyone uses their own key. When you share the extension with colleagues, each person enters their own credentials. Nothing about your account is inside the shared files.
  • Open source. Every line is readable at github.com/mohasoori/clockodo-autofill (MIT license); the privacy policy is docs/PRIVACY.md. You can inspect exactly what is sent — or remove the extension at any time; uninstalling deletes all stored data.

FAQ & troubleshooting

"Not configured — open Options" in the popup

Email or API key missing. Do steps 2–3.

"Entry mode needs a customer and a service"

Do step 4: Load customers & services, select both, Save.

"Work times must match the day's entries"

You're in change-request mode, but this Clockodo derives attendance from time entries. Switch mode to Time entries.

"already filled" but I see nothing in Clockodo

The extension found an existing working time for that date. Check the day in Clockodo's timetable / entries list — possibly an entry booked another way.

Auto-fill didn't run at the set time

Chrome must be running. If it was closed, it catches up the next time Chrome starts. Toggling the switch off and on also triggers an immediate catch-up when the time has passed.

Can I change the hours later?

Yes — Options → Working hours → Save. Future fills use the new times; existing entries are not changed.

Is anything sent anywhere besides Clockodo?

No. Requests go from your browser straight to my.clockodo.com using your own API key. There is no server, analytics, or shared storage.
