Working hours

Same times every day. One block = one continuous stretch of work; add a second block to model a break.
h min
± min
    Every fill draws fresh values: a start inside the window, the break ± its variation, and a 35–65 % morning/afternoon split. The total is always exact; the end follows from it. Running "Replace" again re-rolls the day.
    Block times, the auto-fill time, "today" and weekend detection all use this zone.
